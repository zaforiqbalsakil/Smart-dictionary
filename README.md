# Smart Dictionary & Autocomplete

A C++ based dictionary and autocomplete system using the Trie data structure.

## Features

- Dictionary word search
- Prefix-based autocomplete
- Word suggestions
- Add new words to the dictionary

## Data Structures

- Trie
- Binary Tree

## Language

- C++

## Project Status

This project is being developed and extended as a learning project based on an existing open-source implementation.
